### 🚀 About Me
I'm a technology enthusiast who loves to learn and loves to build. These days I split my time between **leading engineering as CTO of SourceValidate** — a product-authenticity platform that fights counterfeiting with verifiable QR codes — and working as a **Senior AI/ML Engineer at Tyndale USA**, where I design Retrieval-Augmented Generation systems and agentic AI chatbots on AWS Bedrock. I like to think of my work as creating a *neural network of technologies* — not just of tensors.

### 🌟 Recent Highlights
- 🧠 **Senior AI/ML Engineer at Tyndale USA (Nov 2025 – Present)** — building RAG architectures for document-centric QA and optimizing production chatbots with AWS Bedrock Agents.
- 🏗️ **CTO of SourceValidate** — architected a serverless, multi-tenant product-authenticity platform on AWS (Lambda, API Gateway, CloudFront, DynamoDB, Cognito) with a reusable Terraform module, per-tenant SSO, M2M API access, automated billing, and a Bedrock RAG support chatbot.
- 🤖 Shipped agentic AI frameworks with secure tool use and real-time data retrieval.
- 🔒 Championed LLM governance, least-privilege IAM, observability, and cost controls across enterprise AI initiatives.
- 📉 Cut model inference costs **60%** by migrating to AWS Lambda and improved data-pipeline reliability **40%** with Prometheus &amp; Grafana.
- 🎓 Maintained a stack of 10+ certifications across **AWS, Azure, Terraform, and CompTIA**.
